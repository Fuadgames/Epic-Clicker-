# Epic Clicker!

Неоновый кликер с десятью улучшениями, эпическими атаками, событиями и настройками RU/EN + звук.

## Запуск

Откройте `dist/index.html` в браузере. В родительской папке также есть `Играть.html` и автономный `Epic Clicker!.html`.
Для разработки: `npm run dev` → http://127.0.0.1:4173. Для сборки автономного HTML: `node package-portable.cjs`.

## Правила

ЛКМ в любом месте игрового поля приносит клики; кнопки и открытые меню исключены. Пробел тоже работает вне кнопок.
Улучшения покупаются один раз, открываются последовательно и остаются активными. Клики — валюта для покупок.

| Улучшение | Цена | Эффект |
| --- | ---: | --- |
| 0,5× нажатие | 10 | +0,5 к доходу нажатия: 1 + 0,5 = 1,5 |
| Авто-клик | 100 | +1 каждые 5 секунд |
| КЛИК СТЕПЕНИ!!! | 500 | +5 за нажатие и пять дополнительных надписей +1 |
| 1,5× нажатие | 1000 | Ещё +1,5 за нажатие |
| Авто-кликер PRO | 1500 | +5 каждые 2 секунды |
| ЭКСТРА КЛИК +1 | 2000 | Ещё +1 за нажатие |
| ЭПИЧЕСКАЯ АТАКА | 3000 | Каждые 10 ручных нажатий — шанс 50% на +600 за 3 секунды |
| 2× нажатие | 4000 | Ещё +2 за нажатие |
| События | 5000 | Случайное событие каждые 35–55 секунд |
| Авто-кликер ULTRA | 6000 | +100 каждые 3 секунды |

Формула: `1 + 0,5 + 1,5 + 2 + 5 + 1 = 11` при всех ручных улучшениях.
Без улучшений +1. Автокликеры независимы и работают вместе.
Эпическая атака начисляет +20 каждые 100 мс, длится ровно 3 секунды и не продлевается повторными нажатиями.

События: мгновенное удвоение баланса; золотой дождь (+160 за 8 секунд); марафон (25 нажатий за 15 секунд: +250, иначе до −100); перегрузка (10 нажатий за 10 секунд: +150, иначе до −200); импульс удачи (50% +300, иначе до −100).
Меню и скрытая вкладка ставят атаку и события на паузу; автокликеры продолжают работать. За закрытую игру доход не начисляется.

## Сохранения

Прогресс, язык и звук хранятся в localStorage под прежним ключом `epic-clicker-v1`.
Старые балансы и купленные улучшения сохраняются при обновлении. Версия 3 хранит точные четверти клика строками для BigInt, поэтому прежний предел счётчика больше не блокирует ручной доход, атаки и события. Денежные поля Number оставлены для совместимости; точные поля имеют приоритет.
Интернет-сайт, локальный сервер и отдельный HTML имеют независимые сохранения браузера.

## Проверки

`npm test` — экономика, последовательные покупки, все таймеры, награды/штрафы, миграция больших сохранений, RU/EN и связи интерфейса.
`node --check dist/game.js` — синтаксис интерфейса. Поддерживаются уменьшенные анимации через настройки ОС.
